Contact List App

A responsive user list built with Vue 3, TypeScript and Vite.

Features:

1. Gender-specific avatar display
2. Responsive design
3. Fast performance with Vite
4. Type-safe with TypeScript

Technical Stack

Vue 3
TypeScript 5
GitHub Pages(Hosting)

Compile and Hot-Reload for Development: npm run dev

Build for Production: npm run build

Deploy to GitHub Pages: npm run deploy
